# 深大选课助手 v2

深圳大学选课站点（<http://bkxk.szu.edu.cn/>）的油猴脚本辅助工具。

> ⚠️ **仅供技术学习研究。写接口默认关闭，一切使用风险由使用者自负。**
> 本项目不提供登录、不处理验证码、不持久化任何凭证。

---

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开安装链接：

   **https://raw.githubusercontent.com/emo-bird/szu_bkxk/master-tampermonkey-v2/dist/szu_bkxk.user.js**

   Tampermonkey 会弹出安装页，点「安装」即可。
3. 之后脚本会**自动检查更新**（按 `@version` 比对），无需手动重装。

> 首次安装后请到选课页刷新一次，脚本才会在页面上生效。

## 功能

| 功能 | 说明 |
| --- | --- |
| **课程列表优化** | 每张课程卡片显示教学班ID，行距压缩，并注入「添加抢课」「添加监控」两个按钮 |
| **抢课任务** | 任务增删改、启停、优先级、重试策略；执行采用轮转，避免单一课程饿死其它任务 |
| **容量监控** | 支持「单独监控」（逐课查容量）与「类别监控」（拉类别列表）两种模式，可轮询；命中余量可自动抢 |
| **自定义课程** | 手工录入课程，用于课表显示与冲突计算 |
| **冲突计算** | 教学时间解析（周次/单双周/节次），与站点已选课程及自定义课程互查冲突 |
| **响应接管** | 把自定义课程写进站点接口返回：课表多出这些课、课程列表把撞时间的教学班标为冲突 |

## 使用前提

所有功能都依赖页面已登录的 **sessionStorage**（脚本从这里取学号、批次码、校区、令牌）。
若提示缺少这些信息，**刷新选课页**即可。

## 安全设计（红线）

这几条是硬约束，代码里有对应的测试锁住：

1. **写接口默认关闭** —— 关闭时「添加抢课」只打印报文不发送；开启需二次确认。
2. **限流 200ms 硬下限** —— 所有对校园站的请求经同一个串行队列，相邻两条至少间隔 200ms（默认 500ms）。站点对高频请求会直接终止会话。
3. **凭证不落盘** —— token / cookie / 学号只存在于内存，日志不写请求头，localStorage 里也没有它们。
4. **未识别响应必须落档** —— 看不懂的返回会以 `[未识别返回]` 全量打印，便于事后补分支。
5. **不自动启动任务** —— 抢课与监控轮询都必须由你手动点「开始」。

## 使用要点

### 抢课

1. 到选课页，找到想要的课，点卡片上的 **「添加抢课」**（此时只入队，不发请求）
2. 点悬浮窗 →「任务」页 → 确认任务与优先级、重试策略
3. 到「设置」页**开启写接口**（会有二次确认）
4. 点 **「开始抢课」**

**重试策略**（可对每个任务单独设置）：

| 策略 | 行为 |
| --- | --- |
| **智能**（默认） | 满员类失败继续重试；已选过/时间冲突/学分超限等终结性失败立即停止并提示原因 |
| 失败即停 | 任何失败都停 |
| 持续重试 | 任何失败都继续 |

> 判定按业务返回文案。`已选人数超过课容量` 属于**满员**（继续重试），
> 而 `已选mooc课程，每学期只允许4门` 属于**配额用完**（停止）。

### 监控

1. 到选课页点 **「添加监控」**（按钮会变成「移除监控」，再点即取消）
2. 悬浮窗 →「监控」页 → 选择模式、点「开始监控」
3. 命中余量时：写接口开启则自动抢，关闭则只提醒

**两种模式的区别**：

| | 单独监控 | 类别监控（默认） |
| --- | --- | --- |
| 端点 | `teachingclass/capacity.do` | `programCourse.do` 等类别列表 |
| 粒度 | 逐课精确 | 一次拿一类 |
| 余量算法 | `mainClassCapacity - mainElectiveNumber` | `classCapacity - numberOfFirstVolunteer` |

### 自定义课程与响应接管

在「自定义」页签添加课程，时间写法与站点一致：

```
5-18周 星期二 3-4节 致理楼L1-707
1-16周(单) 星期四 1-2节 汇文楼H3-104
5-18周 星期一 1-2节 A,5-18周 星期三 3-4节 B     ← 逗号分隔多段
```

「设置」页有**两个独立开关**：

- **课表注入** —— 让自定义课程出现在课表页
- **列表冲突重算** —— 让课程列表把与自定义课程撞时间的教学班标为冲突

> 若发现自定义课程导致某些课无法选择，**关闭「列表冲突重算」**即可。
> 接管只作用于**站点自己发出的请求**，脚本自身的请求不接管。

## 常见问题

**Q：脚本没反应？**
确认已登录并在选课页或课表页刷新。按 F12 看控制台有无 `SZUBKXK vX.Y.Z 已加载`。

**Q：抢课一直失败，返回 `value sent to redis cannot be null`？**
说明会话失效。刷新页面重新登录。脚本会自动带上 `token` 请求头。

**Q：课表里自定义课程显示了两份？**
响应接管（站点原生渲染）与自绘各一份。到「设置」页**关闭「课表注入」**即可只保留自绘那份。

**Q：日志在哪里看？**
悬浮窗 →「日志」页签，可复制到控制台。

## 开发

```bash
npm test     # 跑测试（170 项，零依赖）
npm run build  # 拼接 src/*.js → dist/szu_bkxk.user.js
npm run check  # 测试 + 构建
```

**改版本号**：只改 `package.json` 的 `version`，构建时会自动写进产物头部与 `NS.VERSION`。

**源码结构**（12 个模块，拼接顺序即依赖顺序）：

```
src/core.js       命名空间 / 日志 / 存储 / 限流队列
src/api.js        报文构造 / 响应分类 / 未识别落档
src/time.js       教学时间解析 / 冲突判定
src/courses.js    被动取数 / 字段映射
src/custom.js     自定义课程
src/monitor.js    容量监控（两种模式 + 轮询 + 命中自动抢）
src/tasks.js      抢课任务与执行引擎
src/list.js       P0 课程列表优化
src/timetable.js  课表页自绘自定义课程
src/hijack.js     接管站点接口响应
src/ui.js         悬浮窗
src/main.js       入口装配
```

接口逆向结论记录在 `docs/开发文档.md`。
