## 四、红线与安全约定（**改动前务必确认**）

1. **写接口默认关闭**：`ENABLE_WRITE_API`（默认 `False`）关闭时，抢课/退课只构造并打印报文，
   **绝不发送**。开启方式见 README「十四、运行期设置」。**不要把默认值改成 True。**
2. **限流不可绕过**：所有学校请求走 `RequestQueue`（默认 500ms/条）。
   `REQUEST_INTERVAL_FLOOR_MS = 200` 是**硬下限**，任何设置都不能低于它。
   站点会因高频请求终止会话（早期未节流的探测踢掉过多组凭证）。
3. **凭证不落盘**：cookie/token 只在内存；日志只记请求网址与表单，**从不记请求头**。
4. **个人敏感信息**：仓库历史已重写清除学号与 Windows 用户名，文档中一律用占位符
   （学号 `2026000000`）。新增文档/日志**不要**写真实学号；`har.json`、`settings.json`、
   浏览器 profile 均已 gitignore。
5. **推送前自检**：`git grep -l '真实学号'`、`git status --short`（确认 `build/` 等未入库）。
6. 使用声明：仅供技术学习研究，禁止大规模恶意抢课，风险自负（程序启动时弹窗强制确认）。

## 六、已知限制与风险

- **只支持 Windows**：WebView2 内嵌依赖 Windows 原生窗口；CDP 备选路线（外部 Edge）也只在 Windows 上验过。
- **页面结构依赖注入**：卡片注入依赖站点 class（`.cv-course-card` 等）。**站点改版会导致注入失效**
  —— 症状是卡片上没有教学班ID/按钮；此时按抓包更新 `INJECT_PAGE_SCRIPT`，并跑 `tools/spike_webview2_embed.py` 自检。
- **会话迁移依赖 profile 隔离**：`在真实浏览器打开` 用的是独立 profile 的 Edge，标签页无法并入日常 Edge
  （不同 profile 是不同实例）。这是**有意**的：避免污染日常浏览器数据。
- **验证码/风控**：站点若引入验证码，内嵌页可人工过，但 `api_client` 的纯 HTTP 链路会被拦。
- **并发抢课能力有限**：全局队列串行 + 500ms 间隔，同一时刻只会有 1 条请求在跑；
  多任务同时命中时按优先级排队，**不是**并发抢。
- **监控任务请求量随类别数线性增长**：建议间隔 2000–3000ms，不要用 500ms 长跑多类别清单。
- 表格未开启排序（避免字符串列按字典序排数字）。

## 九、遇到"没见过的返回"怎么办（运维流程）

这是刻意留的机制：任何**既不是成功（`code=1`）、也不是业务拒绝（`code=2`）、也不是登录失效**的响应，
都会在日志里写一条全量留档：

```
[未识别返回] 该情况尚未处理，已全量留档供后续开发
动作：选课提交
地址：http://bkxk.szu.edu.cn/xsxkapp/sys/xsxkapp/elective/volunteer.do
请求体：{"addParam": "..."}
响应长度：67 字节
响应原文：{"data":null,"msg":"...","code":"9"}
```

处理步骤：

1. 日志面板或 `logs/app_YYYYMMDD.log` 搜索 `[未识别返回]`；
2. 按 `响应原文` 的 `code`/`msg` 判断语义（业务拒绝？风控？结构变更？）；
3. 若属业务拒绝，在 `api_client.classify_response` 里归入对应分支，并在界面上给出可读原因；
4. 若属结构变更，更新解析映射并补一条离线用例；
5. 把结论写进 `docs/接口逆向记录.md`。

**别直接删掉这条日志** —— 它是这个项目"边用边补"的主要反馈回路。

## 十一、给接手者的话

1. **先从 `tools/spike_webview2_embed.py` 开始**：它一次跑完 7 项，能把"内嵌网页能不能用"
   这件事一次性确认清楚，比在界面里瞎点快得多。
2. **改报文前先看 HAR**：`docs/har.json`（未入库，需要自己再抓一份）里有三类真实案例，
   报文能逐字段对照，比猜可靠。
3. **所有校验脚本都是临时的**：跑完即删，输出目录用工作区内 `_itest_out/`
   （系统临时目录在沙箱下不可写）。断言看 `[OK]`/`[FAIL]`，别靠肉眼读 GBK 乱码。
4. **受控环境下命令要提权**：`pip install`、`git push/fetch`、`git filter-branch` 在受限沙箱下会
   分别因临时目录写权限、TLS 凭据、`sh` 管道被拒；API 调用用 Python（`urllib`）比 PowerShell 稳。
5. **别把 `ENABLE_WRITE_API` 打开当默认**：这个开关的默认值是项目的安全底线，
   它的存在意义就是"必须由使用者明确、单独地打开"。
