## 一、这是什么

深大选课站点（`bkxk.szu.edu.cn`）的**油猴脚本**辅助工具。纯 JS，无依赖，无构建器。

**不是**桌面版、**不是** Python 项目 —— 那些在 `master` 分支（PyQt6 桌面版），
两套技术栈**共用一个仓库**，所以 tag 要加 `tm-` 前缀区分（见 §六）。

| 项 | 值 |
| --- | --- |
| 当前版本 | **2.1.0** |
| 产物 | `dist/szu_bkxk.user.js`（127 KB，已入库） |
| 源码 | `src/*.js` 12 个模块，约 3100 行 |
| 测试 | `tests/*.test.mjs` 11 个文件，**163 项**，零依赖 |
| 发布方式 | GitHub raw 自动更新 |

## 二、五分钟上手

```bash
npm test        # 跑全部测试（163 项）
npm run build   # 拼接 src/*.js → dist/szu_bkxk.user.js
npm run check   # 测试 + 构建
```

改代码 → `npm run check` → 在 Tampermonkey 里粘贴产物全文 → 到选课页刷新。

**没有热重载，没有 watch**。这是刻意的：项目太小，加工具链不值得。

## 三、架构：一眼看懂

```
main.js          按 URL 分派：选课页 / 课表页
  ├─ hijack.js   最早安装：接管站点自己的接口响应
  ├─ list.js     选课页：给课程卡片加教学班ID + 两个按钮
  ├─ timetable.js 课表页：自绘自定义课程
  └─ ui.js       悬浮窗（任务/监控/自定义/设置/日志）

支撑模块（被上面调用）：
  core.js        命名空间、日志、存储、限流队列、设置
  api.js         报文构造、响应分类、唯一发送出口
  time.js        teachingPlace 解析、冲突判定
  courses.js     列表取数、字段映射
  custom.js      自定义课程
  monitor.js     容量监控
  tasks.js       抢课任务
```

**拼接顺序 = 依赖顺序**（`scripts/build.mjs` 的 `MODULES`）。模块都是 IIFE，
把自己挂在 `globalThis.SZUBKXK` 上，没有 import/export。

## 四、必须知道的 6 件事

### 1. 所有请求走同一个限流队列

`core.js` 的 `NS.queue` 是**唯一出口**。站点对高频请求会直接终止会话
（v1 实测踢掉过登录态），所以间隔有 **200ms 硬下限**（默认 500ms）。

**不要绕过队列发请求。** 用 `NS.api.send({...})`。

### 2. 写接口默认关闭，且不允许改默认值

`NS.settings().writeApiEnabled` 默认 `false`。判定用
`NS.isWriteAllowed(s)`，它**只认布尔 `true`** —— 字符串 `"true"`、数字 `1` 一律视为关闭。
这是 v1 踩过的坑（`bool("false")` 为真），安全开关上最危险的一类错误。

### 3. 报文形状必须逐字节对齐真机

抢课报文**必须**包一层 `data`：

```json
{"data":{"operationType":"1","studentCode":"...","electiveBatchCode":"...",
         "teachingClassId":"...","isMajor":"1","campus":"01","teachingClassType":"FANKC"}}
```

且**必须**带 `token` 请求头（站点要求 cookie + token 缺一不可）。
这两条都曾漏掉，导致真机失败。`tests/payload.test.mjs` 与 `tests/wire.test.mjs` 锁住了它们。

### 4. `timestamp` 不是所有端点都要

只有 `courseResult.do`、`deleteVolunteer.do` 等少数端点带。
`volunteer.do`、`capacity.do`、`programCourse.do` **都不带**。
开发者文档里那句"URL 统一加 timestamp"是**过度概括**，已修正。

### 5. 站点的数据在全局变量里，不在 DOM 里

教学班数据在 **`window.courseDataList[row.index].tcList`** —— 直接读，不要爬 DOM，
也不要劫持网络去取（那是绕远路）。行有 `index` 属性。

### 6. 响应接管只针对站点请求

站点走 `BH_UTILS.doAjax → jQuery $.ajax → XMLHttpRequest`，我们走 `fetch`。
所以挂 XHR 天然只命中站点。`hijack.js` 里两类接管有**独立开关**，
用户可以关掉（避免自定义课程把课全标成冲突导致选不了课）。

## 五、红线（改代码前务必确认没碰）

1. 写接口默认关闭，**不得**改默认值
2. 限流 200ms 硬下限，**不得**放开
3. 凭证不落盘、日志不写请求头
4. 未识别响应必须落档
5. 前台用户主动运行，不自动启动任务

这五条都有对应测试或代码结构保障。**如果某个改动让它们不再成立，先问用户。**

## 六、发布流程

```bash
# 1) 只改 package.json 的 version（单一来源，构建时注入产物头部 @version 与 NS.VERSION）
npm run check

# 2) 提交
git add -A && git commit -m "chore(release): vX.Y.Z"

# 3) 推送 + 打 tag（注意 tm- 前缀！）
git push origin master-tampermonkey-v2
git tag -a tm-vX.Y.Z -m "油猴脚本 vX.Y.Z（Tampermonkey）"
git push origin tm-vX.Y.Z
```

**为什么 tag 要 `tm-` 前缀**：`master` 分支是 Python 桌面版，历史 tag 是 `v0.3.1`。
两套技术栈共用仓库，不加前缀会混淆（且都在 `v2.x` 量级）。

**发布后务必验证 raw 链接**（自动更新依赖它）：

```
https://raw.githubusercontent.com/emo-bird/szu_bkxk/master-tampermonkey-v2/dist/szu_bkxk.user.js
```

## 七、工作方式：这个项目期望你怎么干活

这是**从 v1 教训里定下的规矩**，请遵守：

1. **有疑问先问用户。** 禁止自行猜测需求、DOM 结构、分发方式后开工。
2. **每轮结束暂停**，索要真机测试结果，不得自行开下一轮。
3. **保持精简。** 加功能前先问"这个真的需要吗"。
4. **不接受"文档里这么写"作为依据。** 报文形状、字段取值、DOM 层级、布局宽度
   —— 都要用**真机抓包**或**站点源码**验证。本项目已因"照抄结论"踩坑两次。

### 两个工具习惯

- **改动含中文的源码，用 Node 写文件，不要用 PowerShell**
  （`Set-Content -Encoding UTF8` 会写 BOM 并损坏中文，曾导致 163 项测试集体失败）。
- **截图反馈很有用。** 用户给的两张截图直接定位了"只增强一种科目"和"抢课模块换行"两个 bug。

## 八、已知问题与未完成

### 未实测（代码写了，但没在真机验证过）

- 方案外 `FAWKC`、重修 `CXKC`、体育 `TYKC`、辅修 `FXKC` 的**类别 → 端点**映射

### 未实现（用户明确不做或尚未要求）

- 退课、收藏
- `noArranged.do` 的自定义课程注入（用户决定只注入 `teachingTime.do`）
- 多标签页协调、数据版本迁移、兼容层

### 已知设计（**不是 bug**，用户确认保留）

- **课表双重显示**：`hijack.js` 让站点原生渲染一份自定义课程，
  `timetable.js` 又自绘一份。两者会同时出现。用户选择了这种方式；
  设置页关掉「课表注入」可只留自绘那份。
- **监控轮询不跨刷新**：刷新后需重新点「开始监控」（红线⑤ 不自动启动任务）。

### 可能出问题的地方（若用户反馈，先查这里）

| 症状 | 先查 |
| --- | --- |
| 接管没生效，`isConflict` 没被改写 | `hijack.js` 的监听是否先于 jQuery。若顺序相反，改用 `open`/`send` 时机劫持 |
| 课表自绘位置整体偏移 | `timetable.js` 的 `top = 28 + (节次-1) × 单节高`；站点若有分段间隔需调基准 |
| 抢课返回 `value sent to redis cannot be null` | 请求头是否带了 `token`（`wire.test.mjs` 覆盖） |
| 按钮点了"没反应" | CSS 里悬停态与选中态是否同色（踩过） |
| 新加的列换行 | 是否写死了宽度（站点是 float + 固定像素，应用 flex 吃剩余空间） |
