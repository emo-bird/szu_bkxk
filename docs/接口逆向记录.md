## 一、已**实测确认**的事实

`http://bkxk.szu.edu.cn/xsxkapp/sys/xsxkapp/` 正确：

| --- | --- | --- |
| `POST /xsxkapp/sys/xsxkapp/elective/batch.do` | 200 JSON，返回选课批次（`typeCode:"02"`、`tacticName:"可选可退"`、`beginTime:"2026-09-24 14:00:00"`、`schoolTerm:"2026-2027-1"`） | 公开 |

### 2. 登录态失效时的服务器行为（重要）

| 请求形态 | 未登录时的响应 |
| --- | --- |
| 普通请求（无 `X-Requested-With`） | **302 → `http://bkxk.szu.edu.cn/xsxkapp/sys/xsxkapp/*default/index.do`**（页面 HTML，长度 18876） |
| 带 `X-Requested-With: XMLHttpRequest` | **401** + HTML 错误页（2267 字节，`<title>401</title>`） |

> **结论**：解析接口响应不能只看状态码。必须
> （a）禁用自动重定向并识别 3xx；（b）带 `X-Requested-With` 以获得明确的 401；
> （c）对 200 但返回 HTML 的情况也判定为登录态失效。
> 代码已据此实现 `api_client.NotAuthenticatedError`。

### 3. token 的传递位置（**推翻/确认参考仓库写法**）

从 `http://xkres.szu.edu.cn/fe_components/bh_utils.js` 取到 `doAjax` 真实签名：

```js
BH_UTILS.doAjax = function (url, params, method, requestOption, headers) {
    var ajaxOptions = $.extend({}, {
        type: method || 'POST',
        url: url,
        data: params || {},
        headers: headers || {},   // ← 第 5 个参数直接作为 jQuery ajax headers
        dataType: 'json',
```

而 `indexBS.min.js` 中的调用：

```js
function queryVolunteered(e){
  var t=(new Date).getTime();
  return BH_UTILS.doAjax(
      BaseUrl+"/sys/xsxkapp/elective/volunteered.do?timestamp="+t,
      e, "post", {}, {token: sessionStorage.token});
}
```

**结论**：
- 接口调用的 token 走 **HTTP 请求头 `token`**（参考仓库写法正确）；
- **每个接口 URL 都附加 `?timestamp=<13位毫秒>`**（参考仓库只给 `courseResult.do` 加了）；
- 与之相对，**页面跳转**的 token 走 **URL query**（见下节）——
  这正好印证需求里「不是所有请求都带 token，部分页面 URL 会自动拼接 token」。

### 4. 「跳转选课网页」必须带 token（用户反馈已实测印证）

`index.min.js` 原文：

```js
var e = sessionStorage.token, t = "";
"01" == m ? t = BaseUrl + "/sys/xsxkapp/*default/curriculavariable.do?token=" + e
          : "02" == m && (t = BaseUrl + "/sys/xsxkapp/*default/grablessons.do?token=" + e),
window.location.href = t
```

`batch.do` 返回的批次 `typeCode` 为 `"02"`（选课），因此当前应进入
**`grablessons.do?token=<token>`**。新开浏览器标签页没有 `sessionStorage`，
所以只能用 URL 传参还原登录上下文 —— 与用户描述完全一致。

代码实现：`api_client.build_elective_page_url(credentials)`。

### 5. 首页重定向行为

`GET http://bkxk.szu.edu.cn/` → **302** → `.../*default/index.do`；
带查询串（如 `/?token=...`）时直接 200。首页 `index.do` 对任何访客都返回 200
（SPA 外壳，长度 18876），**因此 200 不能作为已登录的判据**。

## 三、复现方式

仓库内提供只读探测工具 `tools/probe_api.py`，凭证由环境变量传入、不落盘：

```powershell
$env:SZU_COOKIE = "<从浏览器复制的完整 cookie>"
$env:SZU_TOKEN  = "<sessionStorage.token>"
$env:SZU_STU    = "<学号>"
$env:SZU_BATCH  = "<electiveBatchCode>"
.\.venv\Scripts\python.exe tools\probe_api.py
```

该工具**只调用登录检查与查询类接口**，不含任何写接口调用。
