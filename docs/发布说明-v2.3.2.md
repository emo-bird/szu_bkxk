# 深大选课助手 v2.3.2（Tampermonkey）

> 油猴脚本版。面向 `bkxk.szu.edu.cn`，精简重写，只做三件事：**把课程列表看清楚、把抢课这件事自动化、把自定义课程算进冲突里**。
> 仅用于技术学习研究，使用风险自负。

## 安装

1. 浏览器装 **Tampermonkey**（篡改猴）扩展。
2. 打开 → [`dist/szu_bkxk.user.js`](https://raw.githubusercontent.com/emo-bird/szu_bkxk/master-tampermonkey-v2/dist/szu_bkxk.user.js)
3. Tampermonkey 会弹出安装页，点「安装」。
4. 打开选课站点并登录，右下角出现悬浮窗即成功。控制台会打印 `SZUBKXK v2.3.2 已加载`。

**自动更新**：脚本头已写 `@updateURL`/`@downloadURL` 指向上面那条 raw 链接，之后有新版本 Tampermonkey 会自己提示。

## 本版修复（2.3.1 → 2.3.2）

### 悬浮窗现在会实时显示结果

以前的坑：面板只有一条刷新路径 —— `setInterval(..., 1000)`，而且条件是「任务在跑」。**登录态一失效，任务停止，"在跑"变 false，这条轮询就再也不画了**，你看到的是停机前最后一帧，必须手动刷新页面才知道真实结果。

现在改为：**任何状态变更在落盘时立即重绘**，不再依赖那个轮询条件。运行时请求返回前显示「请求中…」，不再出现黄底整片空白。

### 登录态失效改为弹窗

被站点踢下线时（`code=302`，或响应文案含「登录」），弹出提示框：

> **登录态已失效** — 选课站点已把本次会话踢下线，继续抢课不会成功。请刷新网页并重新登录后再试。

按钮：**「刷新网页重新登录」** 直接刷新，或「稍后」关掉。同一次页面加载只弹一次，不会多任务刷屏。监控轮询发现失效也会**自动停止轮询**，不再空转打服务器。

### 刷新之后不再显示过期的「登录态失效」

上一会话残留的失效提示在你重新登录后会被清掉，任务回到「等待」，可以直接再抢。**其它失败原因与文案原样保留**，不会被一起抹掉。

### 「该课程已经存在选课结果中」现在会正确停下

这条响应原本不在终结判定里，被判成「未知原因」→ **无限重试**。现已归入终结性，任务停止并说明原因。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| **课程列表优化** | 卡片直出**教学班 ID**、压缩行间距、每张卡片加「添加抢课 / 添加监控」两个按钮 |
| **抢课任务** | 「添加抢课」只入队，需你再点「开始抢课」才跑。轮转执行（每轮每个任务各试一次），支持勾选启用/停用 |
| **重试策略** | 默认 **智能区分**：满员类继续重试，终结性原因（已选过 / 冲突 / 学分超限 / 课程不存在）停止。另有「失败即停」「持续重试」 |
| **容量监控** | **单独监控**（盯`capacity.do` 余量）或**类别监控**（按类别轮询列表页，一类只拉一次）。命中余量自动抢 |
| **自定义课程** | 手动录入课名/时间/地点，参与**冲突计算**，并在课表页显示 |
| **冲突检测** | 接管站点接口响应，把自定义课程计入 `isConflict`/`conflictDesc`（只追加、不清除站点已算的冲突） |
| **课表显示** | 站点原生渲染 + 脚本自绘，两条路径并存（可在设置里关掉注入，只留自绘一份） |
| **持久化** | 任务、监控、自定义课程、设置、悬浮窗位置全部落本地，刷新不丢 |

### 悬浮窗

右下角可拖拽浮动面板，可折叠，位置与折叠状态会记住。五个页签：**任务 / 监控 / 自定义 / 设置 / 日志**。

日志页**新内容在上、旧内容在下**。

### 时间参数（设置页可调）

| 参数 | 默认 | 范围 | 作用 |
| --- | --- | --- | --- |
| 请求间隔 | 500ms | 200~60000 | 全局串行队列，所有请求排队发出 |
| 抢课重试间隔 | 1500ms | 200~60000 | 轮转：一轮全部跑完再等这么久 |
| 监控轮询间隔 | 1500ms | 200~60000 | 类别/单独监控的轮询周期 |

## 使用注意

- **写接口默认关闭**，需要你在设置页主动打开。脚本不会自己开始任何任务。
- **请求间隔 200ms 是硬下限**，不要再快 —— 站点会限流甚至把你踢下线（本版弹窗就是为这种情况准备的）。
- **凭证不落盘**：token、学号、批次码、cookie 都不会写进 localStorage。
- 抢课失败会记录**未识别响应**便于排查。

## 常见问题

**Q：脚本没反应？**
确认已登录，并在选课页或课表页刷新。按 F12 看控制台有无 `SZUBKXK v2.3.2 已加载`。

**Q：抢课一直失败，返回 `value sent to redis cannot be null`？**
会话失效。刷新页面重新登录（脚本会自动带上 `token` 请求头）。

**Q：课表里自定义课程显示了两份？**
响应接管（站点原生渲染）与自绘各一份。到「设置」页**关闭「课表注入」**即可只留自绘那份。

## 从源码构建

```bash
npm test       # 192 项测试，零依赖自写 harness
npm run build  # 拼接 src/*.js → dist/szu_bkxk.user.js
npm run check  # 测试 + 构建
```

13 个模块，按依赖顺序拼接：

```
src/limits.js     时间参数上下限（必须先于 core.js）
src/core.js       命名空间 / 日志 / 存储 / 限流队列 / 设置
src/api.js        报文构造 / 响应分类 / 未识别落档 / 统一发送出口
src/time.js       教学时间解析 / 冲突判定
src/courses.js    列表取数 / 字段映射
src/custom.js     自定义课程
src/monitor.js    容量监控（两种模式 + 轮询 + 命中自动抢）
src/tasks.js      抢课任务与执行引擎
src/list.js       课程列表优化
src/timetable.js  课表页自绘自定义课程
src/hijack.js     接管站点接口响应
src/ui.js         悬浮窗
src/main.js       入口装配
```

改版本号只改 `package.json` 的 `version`，构建时自动写进产物头部 `@version` 与 `NS.VERSION`。
