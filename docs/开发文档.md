# 开发文档（v2 · 简要）

> 面向本分支的开发者（也是我）。
> **本文档的核心是"纪律"**：v1 的主要问题不是功能没做出来，而是**做多了**。

---

## 一、三条铁律

1. **有疑问先问用户。** 用户是最直接的解答者；**禁止**自行猜测需求、DOM 结构、分发方式后开工。
2. **每轮结束暂停**，向用户索要真机测试结果。不得自行开下一轮。
3. **保持精简。** 不加用不上的机制；能删就删；先问"这个真的需要吗"。

## 二、测试政策（v2 从简）

**只写核心正确性测试**，其余一律不写：

| 写 | 不写 |
| --- | --- |
| 报文构造（字段顺序/取值） | UI / DOM 测试 |
| 响应分类（成功/业务拒绝/登录失效/未识别） | 端到端集成测试 |
| 教学时间解析（`teachingPlace`） | 边界穷举、异常注入 |
| 冲突判定（单双周/周次/节次） | 覆盖率指标 |
|  | 页内自检、诊断回传包 |
|  | 虚拟时钟、jest 式框架 |

- 一个模块**几条用例即可**，够用就行。
- **能靠眼睛在真机上看出来的，不写测试。**
- 不建"临时校验脚本"体系。

## 三、体积政策

- **少写长中文注释**：只保留"为什么这么做"的关键几行，不复述代码在干什么。
- 模块数量控制在 **~8 个**。
- 目标产物体积：**待用户确认**（拟 ≤ 50KB，作为对照 v1 是 234KB）。
- 不为"将来可能要"预留扩展点。

## 四、技术约定（沿用 v1 已验证结论）

- `@grant none`，页面上下文；复用站点自带的 jQuery 等库，不重复打包。
- **所有对学校站点的请求经同一个限流队列**，间隔硬下限 **200ms**（默认 500ms）。
- **写接口默认关闭**；关闭时只构造并打印报文，不发送。
- 看不懂的响应**全量落档**（`[未识别返回]`），便于事后补分支。
- **凭证只在内存**，日志不写请求头。

## 五、可直接复用的接口结论（免于重新逆向）

完整取证见 v1 分支：`git show master-tampermonkey:docs/接口逆向记录.md`

| 项 | 结论 |
| --- | --- |
| 端点基路径 | `/xsxkapp/sys/xsxkapp/` |
| 鉴权 | **cookie + 请求头 `token` 缺一不可**；URL 统一加 `?timestamp=<13位毫秒>` |
| 抢课 | `POST elective/volunteer.do`，body `addParam=<urlencode(JSON)>`，JSON **必须包一层 `data`**：`{"data":{…}}`，内层字段顺序：`operationType(="1") / studentCode / electiveBatchCode / teachingClassId / isMajor(="1") / campus(="01") / teachingClassType`（HAR 逐字节核对；漏掉 `data` 层会导致抢课失败） |
| 退课 | `POST elective/deleteVolunteer.do`，body `deleteParam=...`，`operationType="2"`，**不带** campus / teachingClassType |
| 查容量 | `POST elective/teachingclass/capacity.do`，body `teachingClassId=..&batchCode=..`；**余量 = `mainClassCapacity - mainElectiveNumber`**（其它字段可能全为 null） |
| 会话取值 | `sessionStorage.studentInfo`（内含 `code` 学号 与 `electiveBatch.code` 批次码）、`sessionStorage.currentCampus.code` 校区、`sessionStorage.token` 令牌、`sessionStorage.teachingClassType` 当前类别。抢课报文按站点 `buildAddVolunteerParam()` 的取法取值 |
| 统一请求出口 | 站点所有请求都走 `window.BH_UTILS.doAjax(url, params, method, requestOption, headers)`（内部 `$.ajax` + `$.Deferred`）。如需拦截/复用，包这一层即可覆盖全部，不必逐 URL 匹配 |
| 响应判别 | `code=1` 成功 / `code=2` 业务拒绝（`msg` 即原因）/ `code=302` 或 msg 含"登录/认证"→ 登录失效 / 其它 → 未识别 |
| 课程字段 | `courseName / courseNumber / courseTotalNumber / teachingClassID / teacherName / teachingPlace / classCapacity / numberOfFirstVolunteer / isMooc / isFull / isConflict / isFavorite / typeName / courseNatureName / departmentName / credit` |
| 课程时间 | `teachingPlace` 形如 `5-18周 星期二 3-4节 致理楼L1-707`；MOOC 可能为 `null` |
| 结构陷阱 | `publicCourse.do`（校公选/慕课）**是扁平结构、没有 `tcList`**，一行即一个教学班；嵌套结构里教学班级级的 `null` **不得覆盖**课程级字段 |
| 类别代码 | `FANKC`(方案内) / `FAWKC`(方案外) / `TJKC`(推荐) / `XGXK`(校公选) / `CXKC`(重修) / `TYKC`(体育) / `FXKC`(辅修) / `MOOC`(慕课)。**`CXKC` 原文档漏列**，读站点 `reloadCourseList()` 补上；抢课报文的 `teachingClassType` 必须用**该教学班所属列表**的类别 |
| 类别 → 端点 | 站点 `grablessonsBS.js`：`programCourse.do`(方案内) / `recommendedCourse.do`(推荐) / `publicCourse.do`(校公选·慕课) / `queryCourse.do`(全校) / `capacity.do`(查容量)；其余类别（方案外/重修/体育/辅修）**未实测** |
| 教学班 DOM | 站点用 `<script type="text/template">` 模板渲染。**行分两类**：①行即教学班（`tpl-public-list-row` / `tpl-mooc-list-row`，带 `tcId` 属性）；②行是课程（其余 7 个模板，无 `tcId`），教学班在全局 `courseDataList[row.index].tcList` 里，点「课程详情」时由 `openCourseTeacherList()` 渲染进 `.cv-row > section > .cv-course-card` |
| 列表布局 | 站点列表是 **float + 固定像素宽度**（`.cv-list>.cv-head>div{width:7.28571%;float:left}`，公选课各列另有写死 px）。**想加列不能写死宽度**，否则放不下会换行；应改 flex 让新列吃剩余空间 |
| 页面 | 选课页 `*default/grablessons.do`、课表页 `*default/curriculum.do`（**课表页 DOM 尚未取证**） |

## 六、模块规划（草案，待用户确认后再动）

拟 8 个源文件拼接为单文件 `.user.js`：

```
src/core.js     命名空间 / 日志 / 存储 / 限流队列
src/api.js      报文构造 + 响应分类 + 未识别落档
src/time.js     教学时间解析 + 冲突判定
src/courses.js  被动取数 + 字段映射 + 筛选排序（P0 的数据基础）
src/list.js     课程列表优化（P0 界面）
src/tasks.js    抢课任务与执行
src/ui.js       悬浮窗（任务 / 设置 / 日志）
src/main.js     入口装配
```

## 七、红线（不可放松）

1. 写接口默认关闭，**不得**改默认值
2. 限流 200ms 硬下限，**不得**放开
3. 凭证不落盘、日志不写请求头
4. 未识别响应必须落档
5. 前台用户主动运行，不自动启动任务
