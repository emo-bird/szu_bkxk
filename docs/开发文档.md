# 开发文档（v2）

> 面向本分支的开发者（也是我）。
> **本文档的核心是"纪律"**：v1 的主要问题不是功能没做出来，而是**做多了**。

分支：`master-tampermonkey-v2`　｜　当前版本：**2.1.0**　｜　产物：`dist/szu_bkxk.user.js`（127 KB / 12 模块）

---

## 一、三条铁律

1. **有疑问先问用户。** 用户是最直接的解答者；**禁止**自行猜测需求、DOM 结构、分发方式后开工。
2. **每轮结束暂停**，向用户索要真机测试结果。不得自行开下一轮。
3. **保持精简。** 不加用不上的机制；能删就删；先问"这个真的需要吗"。

> 实践中的教训：凡是"看起来顺手"的推断（报文形状、字段取值来源、DOM 层级、
> 布局宽度），**都必须先用真机抓包或站点源码验证**。本项目已经因为"照抄文档结论"
> 踩过两次坑（报文漏 `data` 层、漏 `token` 请求头）。

## 二、测试政策

**只写核心正确性测试**，其余一律不写：

| 写 | 不写 |
| --- | --- |
| 报文构造（字段顺序/取值/逐字节比对） | UI / DOM 渲染效果 |
| 实际发出的请求（URL / 请求头 / body，用假 fetch 捕获） | 端到端集成测试 |
| 响应分类（成功/业务拒绝/登录失效/未识别） | 边界穷举、异常注入 |
| 教学时间解析（`teachingPlace`） | 覆盖率指标 |
| 冲突判定（单双周/周次/节次） | 页内自检、诊断回传包 |
| 重试策略分类、持久化、接管改写 | 虚拟时钟、jest 式框架 |

- 一个模块**几条用例即可**，够用就行。
- **能靠眼睛在真机上看出来的，不写测试。**
- 不建"临时校验脚本"体系。
- **测试文件只增不删**：报文构造的测试曾在重构中被误删，导致 `addParam` 少一层 `data`
  的 bug 一直没被发现。故 `payload.test.mjs` 单独成文件。

当前：**11 个测试文件 / 163 项用例 / 零依赖自写 harness**（`npm test`）。

## 三、体积与注释政策

- **少写长中文注释**：只保留"为什么这么做"的关键几行，不复述代码在干什么。
- 模块数量：**12 个**（`src/` 共约 3100 行）。
- 产物体积：**已取消上限**（用户明确要求）。当前 127 KB，作为对照 v1 是 234 KB。
- 不为"将来可能要"预留扩展点。
- **不引入构建器、依赖、框架**：`scripts/build.mjs` 只做字符串拼接。

## 四、技术约定

- `@grant none`，页面上下文；复用站点自带的 jQuery，不重复打包。
- `@run-at document-start`（响应接管必须尽早安装），DOM 操作等 `DOMContentLoaded`。
- **所有对学校站点的请求经同一个限流队列**，间隔硬下限 **200ms**（默认 500ms）。
- **写接口默认关闭**；关闭时只构造并打印报文，不发送。
- 看不懂的响应**全量落档**（`[未识别返回]`），日志行带 `code` 与 `msg`，便于事后补分支。
- **凭证只在内存**，日志不写请求头；localStorage 只存任务/监控/自定义课程/设置。

## 五、接口结论（全部经真机抓包或站点源码核对）

> ⚠️ 下表是**唯一可信来源**。v1 的 `docs/接口逆向记录.md` 已在归档分支，
> 且有若干结论被本分支修正（见"曾踩的坑"）。

### 5.1 通用

| 项 | 结论 |
| --- | --- |
| 端点基路径 | `/xsxkapp/sys/xsxkapp/` |
| 鉴权 | **cookie + 请求头 `token` 缺一不可**（漏 token 会被服务端以 Redis 报错拒绝） |
| `timestamp` | **不是所有端点都要**。`volunteer.do`/`capacity.do`/`programCourse.do`/`publicCourse.do`/`recommendedCourse.do` **都没有** query；只有 `courseResult.do`/`deleteVolunteer.do`/`celebrityfamous.do` 等带。代码里默认**不加**，需要时显式 `o.timestamp=true` |
| 响应判别 | `code=1` 成功 / `code=2` 业务拒绝（`msg` 即原因）/ `code=302` 或 msg 含"登录/认证"→ 登录失效 / 其它 → 未识别 |
| 会话取值 | `sessionStorage.studentInfo`（含 `code` 学号 与 `electiveBatch.code` 批次码）、`sessionStorage.currentCampus.code` 校区、`sessionStorage.token` 令牌。抢课报文按站点 `buildAddVolunteerParam()` 的取法取值 |
| 统一请求出口 | 站点所有请求都走 `window.BH_UTILS.doAjax(url, params, method, requestOption, headers)`（内部 `$.ajax` + `$.Deferred`）|

### 5.2 写接口

| 项 | 结论 |
| --- | --- |
| 抢课 | `POST elective/volunteer.do`，body `addParam=<urlencode(JSON)>`，JSON **必须包一层 `data`**：`{"data":{…}}`，内层字段顺序 `operationType(="1") / studentCode / electiveBatchCode / teachingClassId / isMajor(="1") / campus / teachingClassType` |
| 退课 | `POST elective/deleteVolunteer.do`，body `deleteParam=...`，`operationType="2"`，**不带** campus / teachingClassType（**本分支未实现退课**）|

### 5.3 只读接口

| 项 | 结论 |
| --- | --- |
| 查容量 | `POST elective/teachingclass/capacity.do`，body `teachingClassId=..&batchCode=..`；**余量 = `mainClassCapacity - mainElectiveNumber`**，其余字段可能全为 null → 缺失时返回 **null**（不是 0） |
| 课程列表 | `POST elective/{programCourse,publicCourse,recommendedCourse,queryCourse,minorCourse,retakeCourse,sportCourse,unProgramCourse}.do`，body `querySetting=<urlencode(JSON)>`，内层 `{data:{…},pageSize,pageNumber,order,orderBy}` |
| 规则课表 | `POST elective/teachingTime.do`，body `studentCode=..`，返回 `{totalCount,dataList[]}`，每条 = **一个上课时段**：`dayOfWeek(1..7)/beginSection/endSection/weekName/week`。`week` 是**周次位图**（`000011111111111111` = 第 5-18 周，下标 0 为第 1 周；长度不固定，样本里有 18 位与 11 位） |
| 未安排时间 | `POST elective/noArranged.do`，body `studentCode=..`，同构扁平列表，`teachingPlace` 为 null（MOOC 等） |

### 5.4 字段与结构

| 项 | 结论 |
| --- | --- |
| 课程字段 | `courseName / courseNumber / courseTotalNumber / teachingClassID / teacherName / teachingPlace / classCapacity / numberOfFirstVolunteer / isMooc / isFull / isConflict / isFavorite / typeName / courseNatureName / departmentName / credit` |
| 课程时间 | `teachingPlace` 形如 `5-18周 星期二 3-4节 致理楼L1-707`；**两种空格风格**（HAR-1 有空格、HAR-2 无空格）都要兼容；MOOC 可能为 `null` |
| 结构陷阱 | `publicCourse.do`（校公选/慕课）**是扁平结构、没有 `tcList`**，一行即一个教学班；嵌套结构里教学班级级的 `null` **不得覆盖**课程级字段 |
| 类别代码 | `FANKC`(方案内) / `FAWKC`(方案外) / `TJKC`(推荐) / `XGXK`(校公选) / `CXKC`(重修) / `TYKC`(体育) / `FXKC`(辅修) / `MOOC`(慕课)。**`CXKC` 原文档漏列**；抢课报文的 `teachingClassType` 必须用**该教学班所属列表**的类别，不能用全局设置 |
| 类别 → 端点 | 站点 `grablessonsBS.js`：`programCourse.do`(方案内) / `recommendedCourse.do`(推荐) / `publicCourse.do`(校公选·慕课) / `queryCourse.do`(全校) / `capacity.do`(查容量)；其余类别（方案外/重修/体育/辅修）**未实测** |
| 冲突字段 | 站点**自己已经算好冲突**：`isConflict`(`"0"`/`"1"`) 与 `conflictDesc`（如 `C程序设计(5-18周星期三3-4节)`）。我们只**追加**自定义课程导致的冲突，绝不清除原值 |

### 5.5 DOM

| 项 | 结论 |
| --- | --- |
| 教学班列表 | 站点用 `<script type="text/template">` 模板渲染。**行分两类**：①行即教学班（`tpl-public-list-row`/`tpl-mooc-list-row`，带 `tcId`）；②行是课程（其余 7 个模板，无 `tcId`），教学班在全局 `courseDataList[row.index].tcList` 里，点「课程详情」时由 `openCourseTeacherList()` 渲染进 `.cv-row > section > .cv-course-card` |
| 列表布局 | **float + 固定像素宽度**（`.cv-list>.cv-head>div{width:7.28571%;float:left}`，公选课各列另有写死 px）。**加列不能写死宽度**，否则放不下会换行；应改 flex 让新列吃剩余空间。表头列加 `cv-normal` 可抑制排序箭头 |
| 课表页 | `#myCourseTable > .cv-my-course > .cv-col.cv-left`（`.cv-lesson` 刻度，单节 54px）+ `.cv-col.cv-right`（每天一列，`.cv-head` 写「周一…周七」）；一节课 = `.cv-lesson[start][end][top]`，内含 `.cv-course-card-single` |
| 页面 | 选课页 `*default/grablessons.do`、课表页 `*default/curriculum.do` |

### 5.6 响应接管

站点请求走 `BH_UTILS.doAjax → jQuery $.ajax → **XMLHttpRequest**`；本脚本走 **`fetch`**。
故**挂 XHR 即只接管站点请求**；fetch 亦挂（防御），用 `init.__szuSkip` 显式放行脚本自己的请求。

改写手段：在实例上 `Object.defineProperty(xhr,'responseText',{get})`。
我们的 `readystatechange` 监听在 **XHR 构造时**注册，先于 jQuery 注册，故先于它读取。

## 七、红线（不可放松）

1. 写接口默认关闭，**不得**改默认值
2. 限流 200ms 硬下限，**不得**放开

## 九、曾踩的坑（不要在同一个地方摔倒两次）

| 坑 | 表现 | 根因 | 已固化为 |
| --- | --- | --- | --- |
| 报文漏 `{"data":…}` 外层 | 抢课必失败 | 照抄文档结论，没逐字节核对抓包；且报文测试曾被误删 | `payload.test.mjs` 逐字节比对 HAR |
| 漏 `token` 请求头 | 服务端报 `value sent to redis cannot be null` | `API.send` 只在显式传 `o.token` 时才加头，调用点都忘了传 | `wire.test.mjs` 用假 fetch 断言请求头 |
| 多带 `timestamp` | 与站点真实请求不一致 | 把"URL 统一加 timestamp"当成对所有端点成立 | `wire.test.mjs` 断言默认不带 |
| 类别来源用错 | 抢课投到错误的类别 | 用全局 `monitorCategory` 而非该教学班所属列表的类别 | `tasks.test.mjs` + `list.test.mjs` |
| 会话字段取错来源 | 批次码为空 | 站点抢课用的是 `studentInfo.electiveBatch.code`，不是 `currentBatch` | `wire.test.mjs` + `list.test.mjs` |
| 加列写死宽度 | 新列换行、错位 | 站点是 float + 固定像素宽度，剩余空间不足 | `list.test.mjs`（结构级）|
| 悬停态与选中态同色 | 按钮"点了没反应" | 两者都是同一种实心蓝，鼠标未移开时看不出切换 | 悬停改浅色 + 按钮文字随状态切换 |
| 用 PowerShell 改含中文的源码 | 文件被写 BOM 且中文损坏，163 项测试集体失败 | `Set-Content -Encoding UTF8` 的行为 | **改用 Node 写入**；产物构建后校验无 BOM、无替换字符 |
