## 三、架构与模块契约

依赖方向（上层依赖下层，UI **不得**直接写网络逻辑）：

```
main.py
  └─ ui_main.py ──→ api_client.py ──→ request_queue.py ──→ aiohttp
                      └─ auth_model.py
        └─ task_model.py / course_model.py
              └─ logger_util.py / config.py
```

| 模块 | 职责 | 关键公开接口（拟定） |
| --- | --- | --- |
| `config.py` | 全部常量、路径、开发开关 | `REQUEST_INTERVAL_MS`、`MAX_QUEUE_SIZE`、`ENABLE_WRITE_API`、`BASE_URL`、路径常量 |
| `auth_model.py` | 身份凭证数据类 | `Credentials(student_code, elective_batch_code, cookie, token)`、`is_complete()`、`missing_fields()` |
| `request_queue.py` | 全局异步优先级限流队列 | `RequestQueue.submit(coro_factory, priority)`、`start()`、`stop()`、`QueueFullError` |
| `api_client.py` | aiohttp 封装 + 报文构造 | `query_courses(...)`、`query_selected(...)`、`favorite(...)`、`build_enroll_payload(...)`（仅构造） |
| `task_model.py` | 抢课任务模型 + 序列化 | `GrabTask`、`load_tasks()`、`save_tasks()`、`clamp_interval()` |
| `course_model.py` | 课程模型 + 缓存 | `Course`、`load_cache()`、`save_cache()` |
| `ui_main.py` | PyQt6 主窗口/3 个标签页/信号槽 | `MainWindow` |
| `logger_util.py` | 日志分发 | `Logger`、`log(source, level, message)`、`LogFilter` |
| `main.py` | 入口：风险弹窗、初始化、Qt + asyncio 事件循环 | `main()` |

### 关键设计决策（待实现时确认）

1. **并发模型**：Qt 主线程负责 UI；异步逻辑跑在独立的 asyncio 事件循环线程中，
   通过 Qt 信号槽跨线程回传结果（避免 qasync 附加依赖）。
2. **队列调度**：单个调度协程循环，每 `REQUEST_INTERVAL_MS` 从 `PriorityQueue` 取 1 条执行；
   入队时若 `len(queue) >= MAX_QUEUE_SIZE` 直接丢弃 + 告警，不阻塞 UI。
3. **单任务节流**：任务自身轮询间隔以 `max(配置值, REQUEST_INTERVAL_MS)` 参与调度，
   避免任务把全局队列打满。
4. **任务状态机**：`WAITING / RUNNING / SUCCESS / STOPPED / FAILED`；
   启动恢复后强制 `STOPPED`，需用户手动启动。
5. **凭证安全**：凭证仅存内存，**不写入**任务 JSON 与缓存 JSON；不落盘即不泄露。
6. **本地文件规划**（均加入 `.gitignore`）：
   - `courses_cache.json`（项目根目录，课程列表缓存）
   - `tasks_config.json`（项目根目录，抢课任务配置）
   - `logs/app_YYYYMMDD.log`（日志文件）

`querySetting` 内层结构（参考仓库）：

```json
{
  "data": {
    "studentCode": "<学号>", "campus": "01", "electiveBatchCode": "<批次>",
    "isMajor": "1", "teachingClassType": "FANKC",
    "checkConflict": "2", "checkCapacity": "2", "queryContent": "MOOC:2,"
  },
  "pageSize": "10", "pageNumber": "1", "order": "", "orderBy": "courseNumber"
}
```

`teachingClassType` 取值：`FANKC` 方案内｜`FAWKC` 方案外｜`TJKC` 本班｜`XGXK` 校公选｜
`TYKC` 体育｜`FXKC` 辅修｜`MOOC` 慕课。

写接口 `addParam` 报文字段（参考仓库 `choose_course.start_choose`）：

```json
{"data": {"operationType": "1", "studentCode": "<学号>", "electiveBatchCode": "<批次>",
          "teachingClassId": "<教学班ID>", "isMajor": "1", "campus": "01",
          "teachingClassType": "FANKC", "chooseVolunteer": "1"}}
```

Request Header 参考（`szu/setting.py`）：`Cookie`、`token`、
`Content-Type: application/x-www-form-urlencoded; charset=UTF-8`、`Host`、`User-Agent`、
`Accept`、`Accept-Language`、`Pragma: no-cache`。
**注意**：需求 §二.3 明确「不是所有请求都带 token」，各接口的鉴权位置（header / query / body）
必须逐个按抓包结果确定，不得统一塞进同一处。

响应字段（参考仓库已解析到的部分，用于表格列映射推演）：

- 课程级 `dataList[]`：`courseName`
- 教学班级级 `tcList[]`：`teachingClassID`、`teacherName`、`teachingPlace`、
  `isFull`、`isConflict`、`isChoose`、`numberOfFirstVolunteer`、`classCapacity`、
  `numberOfSelected`、`conflictDesc`
